### 1. What is the difference between a function parameter and a function
argument?

> Function parameter is the placeholder in the function definition. While function
arguments are the actual values passed to the function when it is called.

### 2. How does the `this keyword allow an object method to reference properties
within the same object?
> The 'this' keyword refers to the specific object that is executing the method.
This allows the method to access and modify the object's properties without
hardcoding the object's name.

### 3. Why is modularizing code using import' and `export' useful in modern
JavaScript development?
> Because it breaks large application to smaller and reusable files which makes
the code easier to organize and maintain. It also keeps variables scoped to their
own files.

### 4. Why is it important to run `git pull origin main` before creating new
